IMPLEMENTATION DETAILS:
═══════════════════════════════════════════════════════════════════════════

Resume Upload Feature:
  • Applicants can attach resume when applying
  • Supported formats: PDF, DOC, DOCX
  • Max file size: 5MB
  • Storage: storage/app/public/applications/{job_posting_id}/{timestamp}_{filename}

Resume Download Feature:
  • HR/SuperAdmin users can download resumes
  • Authorization check: Only super_admin and admin roles
  • Audit logging for all downloads
  • 403 Forbidden error for unauthorized users

Application Pipeline:
  • Applied → Shortlisted → Interviewed → Hired/Rejected
  • Visual pipeline display in application details
  • Status updates with optional notes
  • Interview date tracking
