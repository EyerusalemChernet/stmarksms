   - Status: ✓ FIXED

2. MISSING RESUME DISPLAY
   - Error: Resume section not visible in application details
   - Cause: No resume display code in application_show.blade.php
   - Fix: Added resume section with download button
   - Status: ✓ FIXED

3. MISSING RESUME DOWNLOAD LINK
   - Error: No way to download resume files
   - Cause: Resume display code was missing
   - Fix: Added download link using route('hr.recruitment.applications.download-resume')
   - Status: ✓ FIXED

================================================================================
CHANGES MADE:
================================================================================

FILE 1: app/Models/JobApplication.php
--------
Added PIPELINE constant:
  const PIPELINE = ['applied', 'shortlisted', 'interviewed', 'hired', 'rejected'];

This constant is used in application_show.blade.php to display the pipeline
visualization showing the application's progress through the hiring process.

FILE 2: resources/views/pages/hr/recruitment/application_show.blade.php
--------
Added resume display section:
  - Checks if application has resume using $application->hasResume()
  - Displays resume filename
  - Provides download button with authorization check
  - Only shows if resume exists
  - Styled with green border to highlight importance
