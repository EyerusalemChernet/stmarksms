┌─ UPLOAD CERTIFICATE FLOW ────────────────────────────────────────────────┐
│                                                                            │
│  USER ACTION                                                               │
│    │                                                                       │
│    ├─→ Go to HR → Employees                                               │
│    │                                                                       │
│    ├─→ Select Employee                                                    │
│    │                                                                       │
│    ├─→ Click "Edit Profile"                                               │
│    │   └─→ Load profile_edit.blade.php                                    │
│    │                                                                       │
│    ├─→ Scroll to "Qualifications" Section                                 │
│    │   └─→ Show qualification form with file upload                       │
│    │                                                                       │
│    ├─→ Fill in Qualification Details                                      │
│    │   ├─→ Degree (required)                                              │
│    │   ├─→ Field of Study (optional)                                      │
│    │   ├─→ Institution (optional)                                         │
│    │   └─→ Graduation Year (optional)                                     │
│    │                                                                       │
│    ├─→ Select Certificate File                                            │
│    │   ├─→ Validate file type (PDF, DOC, DOCX, JPG, PNG)                  │
│    │   ├─→ Validate file size (max 5MB)                                   │
│    │   └─→ Display file name                                              │
│    │                                                                       │
│    ├─→ Click "Save Changes"                                               │
│    │   └─→ Submit form to updateProfile()                                 │
│    │                                                                       │
│    └─→ BACKEND PROCESSING                                                 │
│        │                                                                   │
│        ├─→ HRController::updateProfile()                                  │
│        │   └─→ Validate all inputs                                        │
│        │                                                                   │
│        ├─→ HRController::updateQualifications()                            │
│        │   ├─→ For each qualification:                                    │
│        │   │   ├─→ Check if file uploaded                                 │
│        │   │   ├─→ Store file in storage/qualifications/{emp_id}/         │
│        │   │   ├─→ Save path to database                                  │
│        │   │   └─→ Create/Update qualification record                     │
│        │   │                                                               │
│        │   └─→ Return success message                                      │
│        │                                                                   │
│        └─→ ✅ CERTIFICATE UPLOADED                                        │
│            Redirect to profile                                            │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
