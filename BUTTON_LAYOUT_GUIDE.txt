TYPICAL WORKFLOW
════════════════════════════════════════════════════════════════════════════

1. VIEW PAYROLL LIST
   └─ Go to HR → Payroll
   └─ Select month and status filters (optional)
   └─ See all employees and their payroll status

2. EXPORT (If needed)
   └─ Click [Export PDF] or [Export CSV] at top right
   └─ Downloads complete list for reporting

3. REVIEW INDIVIDUAL PAYROLL
   └─ Click [View] icon for any employee
   └─ Review details, calculations, breakdowns
   └─ Optional: Download individual PDF/CSV from detail page

4. EDIT DRAFT PAYROLL (If needed)
   └─ Click [Edit] icon on draft payroll
   └─ Make corrections/adjustments
   └─ Save changes

5. APPROVE PAYROLL
   └─ Click [✓ Approve] button for draft payroll
   └─ Confirms → Status changes to "Approved"

6. MARK AS PAID
   └─ Click [💰 Mark Paid] button for approved payroll
   └─ Confirms → Status changes to "Paid"
   └─ Process complete
