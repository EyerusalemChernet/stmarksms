# 🚀 Quick Setup Guide

## Employee Qualification Certificate Upload Feature

The system now supports uploading and managing employee qualification certificates!

---

## ⚡ Quick Start (2 Minutes)

### Step 1: Run Setup
Open your browser and go to:
```
http://127.0.0.1:8000/quick-setup.php
```

Wait for the page to show **"✅ Setup Complete!"**

### Step 2: Refresh Browser
Press **Ctrl+F5** (Windows) or **Cmd+Shift+R** (Mac)

### Step 3: Test It
1. Go to **HR → Employees**
2. Click on any employee
3. Click **"Edit Profile"**
4. Scroll to **"Qualifications"**
5. Upload a certificate file
6. Click **"Save Changes"**
7. Go back to profile - you should see the certificate! ✅

## 🆘 Issues?

### Still not working?
1. Clear browser cache: **Ctrl+Shift+Delete**
2. Close and reopen browser
3. Run setup again: `http://127.0.0.1:8000/quick-setup.php`

### Need command line?
Run one of these:
- **Command Prompt:** `setup-qualifications.bat`
- **PowerShell:** `setup-qualifications.ps1`

### Check logs
```bash
type storage\logs\laravel.log
```
