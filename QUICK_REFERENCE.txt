┌─ USING THE FEATURE ──────────────────────────────────────────────────────┐
│                                                                            │
│  UPLOAD A CERTIFICATE:                                                    │
│     1. Go to: HR → Employees                                              │
│     2. Click on an employee name                                          │
│     3. Click "Edit Profile" button                                        │
│     4. Scroll to "Qualifications" section                                 │
│     5. Fill in: Degree, Field of Study, Institution, Graduation Year     │
│     6. Click "Choose file" and select a certificate                       │
│     7. Click "Save Changes"                                               │
│                                                                            │
│  VIEW CERTIFICATES:                                                       │
│     1. Go to: HR → Employees                                              │
│     2. Click on an employee name                                          │
│     3. Scroll to "Qualifications" section                                 │
│     4. Click the certificate link to download                             │
│                                                                            │
│  EDIT QUALIFICATIONS:                                                     │
│     1. Go to: HR → Employees → Select Employee                            │
│     2. Click "Edit Profile"                                               │
│     3. Modify the qualification details                                   │
│     4. Upload a new certificate if needed                                 │
│     5. Click "Save Changes"                                               │
│                                                                            │
│  DELETE QUALIFICATIONS:                                                   │
│     1. From Edit Profile: Click "Remove" button                           │
│     2. From Profile View: Click trash icon in Qualifications table        │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
