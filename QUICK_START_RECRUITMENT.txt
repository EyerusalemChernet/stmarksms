KEY FEATURES:
═══════════════════════════════════════════════════════════════════════════

📋 Job Postings
   • Create, edit, delete job postings
   • Set employment type, vacancies, deadline
   • Track application counts

📝 Job Applications
   • Submit applications with resume attachment
   • Resume validation (PDF, DOC, DOCX, max 5MB)
   • Track application status

📊 Pipeline Management
   • Applied → Shortlisted → Interviewed → Hired/Rejected
   • Update status with notes
   • Visual pipeline display

📥 Resume Management
   • Upload resume with application
   • Download resume (HR/SuperAdmin only)
   • Audit logging for all downloads

👤 Employee Conversion
   • Convert hired applicants to employees
   • Pre-fill employee form with applicant data

VALIDATION RULES:
═══════════════════════════════════════════════════════════════════════════

Application Submission:
  • job_posting_id: required, exists in job_postings
  • first_name: required, max 80 chars
  • last_name: required, max 80 chars
  • email: optional, valid email
  • phone: optional, max 20 chars
  • address: optional, max 255 chars
  • resume: optional, PDF/DOC/DOCX, max 5MB
  • cover_letter: optional, text


AUTHORIZATION:
═══════════════════════════════════════════════════════════════════════════

Recruitment Module Access:
  • Requires: HR Manager role
  • Middleware: hr_manager

Resume Download:
  • Requires: super_admin or admin role
  • Returns: 403 Forbidden if unauthorized
