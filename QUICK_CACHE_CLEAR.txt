Step 1: Open Command Prompt

Step 2: Navigate to project:
   cd c:\laragon\www\stmarksms

Step 3: Run these commands one by one:
   php artisan cache:clear
   php artisan config:clear
   php artisan view:clear
   php artisan route:clear

Step 5: Go to HR → Contract Management

Done! You should now see all the fixes.

✅ WHAT YOU'LL SEE AFTER CLEARING CACHE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Confirmation Dialog
   When you click "Renew Contract", you'll see a confirmation dialog
   asking to confirm the renewal.

2. Readable Date Format
   The modal will show both ISO format (2026-05-18) and readable format
   (May 18, 2026).

3. Max Date Validation
   If you try to set a date more than 10 years in future, you'll see
   a validation error.

4. Consistent Days
   The "Expiring (60 days)" card will now link to 60 days (not 30).

5. Consistent Audit Log
   Contract renewals will show consistent date format in audit log.
